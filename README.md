J'ai réalisé cette application avec le framework PHP Laravel.

L'objectif de cet exercice était d'apprendre à maîtriser un framework PHP, de mettre en place une architecture robuste pour gérer plusieurs entités (boxes, propriétaires, locataires, contrats, paiements) tout en garantissant la sécurité des données et la simplicité d’utilisation.

L’application permet à un utilisateur de :
- Gérer des boxes (création, modification, disponibilité)
- Suivre des locataires et des contrats de location
- Gerer des modèles de contrats de location
- Gerer des contrats automatisée : l'utilisateur peut créer un modèle de contrat, en y incluant des variables (nom, prenom, adresse, etc...) qui seront par la suite automatiquement remplacées lors de la constitution d'un contrat.
- Suivre les paiements et générer automatiquement les factures

## Compétences techniques

- Laravel
- Blade
- TailwindCSS
- Vite
- Github Actions CI/CD

Le projet n'est, pour le moment, plus hébergé.
